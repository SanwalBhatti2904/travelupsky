# Voyage — Modern Travel Experience Website

A sleek, interactive, and responsive travel agency website designed to deliver a premium user experience. Built with modern web standards, smooth animations, and advanced scroll interactions.

## ✨ Features

- **Interactive Full-Screen Menu Overlay:** Smooth entrance menu featuring dynamically changing background imagery on link hover.
- **Auto-Hiding Navbar:** Responsive top navigation bar that intelligently hides on scroll down and reappears on scroll up.
- **Scroll-Driven Destination Carousel:** A pinned vertical image slider that updates active slide numbers and progress tracking as you scroll.
- **Dynamic Bento Grid:** Modern bento-box grid showcase with pinned scroll animations on desktop and smooth reveals on mobile devices.
- **Frosted Glass Beach Section:** Contemporary UI featuring a split-card design with backdrop filters and glassmorphism.
- **Smooth Inertial Scrolling:** Integrated with Lenis for butter-smooth scrolling across desktop and mobile screens.
- **Fully Responsive Design:** Optimized layouts for desktops, tablets, and smartphones.

## 🛠️ Tech Stack

- **Structure:** HTML5 (Semantic Structure)
- **Styling:** Vanilla CSS3 (CSS Variables, Grid, Flexbox, Glassmorphism, CSS Animations)
- **Typography:** [Google Fonts](https://fonts.google.com/) (*Anton, Mona Sans, Space Grotesk, Inter*)
- **Icons:** [FontAwesome 6](https://fontawesome.com/)
- **Animations:** 
  - [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
  - GSAP ScrollTrigger
  - GSAP SplitText
- **Smooth Scroll:** [Lenis](https://lenis.darkroom.engineering/)

## 🚀 Getting Started

To run this project locally on your machine, follow these simple steps:

### Prerequisites

You only need a modern web browser and a local development server (or code editor extension such as VS Code Live Server).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SanwalBhatti2904/travelupsky.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd travelupsky
   ```

3. **Launch the application:**
   - Open `index.html` directly in your browser, **or**
   - Serve using VS Code's **Live Server** extension or `npx serve`.
